# songora

Responsive React/Vite Demo mit Webseitensprachen:

- Deutsch
- English
- Türkçe

Die gewählte Webseitensprache wird im Browser gespeichert und bleibt beim nächsten Besuch erhalten.

## Lokal starten

```bash
npm install
npm run dev
```

## Vercel

Framework: Vite  
Build Command: `npm run build`  
Output Directory: `dist`
